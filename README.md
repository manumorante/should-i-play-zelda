# Should I play Zelda?

A completely scientific test. Every answer is valid. The result is inevitable.

Based on a classic internet flowchart, turned into an animated quiz in English and Spanish.

- Single `index.html`, no build step, no dependencies.
- Language is detected from the browser and can be switched with the ES | EN pill. You can force it with `?lang=en` or `?lang=es`.

## Run locally

Open `index.html` in a browser.

## Deploy

Every push to `main` is deployed automatically by Vercel.
